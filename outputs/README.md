# Ativos da identidade Radar

- `radar-identidade-visual.html`: guia navegável da identidade “Camadas Vivas”.
- `radar-identidade-board.png`: prancha consolidada da marca.
- `radar-camadas-vivas.png`: conceito visual aprovado para o produto.
- `radar-logo-*.svg` e `radar-app-icon.svg`: sistema de marca vetorial.
- `radar-design-tokens.css` e `.json`: tokens para implementação.
- `assets/fonts/`: fontes locais e respectivos arquivos OFL.
- `*.prompt.txt`: proveniência dos visuais gerados.

Os ZIPs de entrega são ignorados pelo Git porque duplicam os mesmos arquivos. O nome Radar e as
imagens conceituais não constituem comprovação de registro de marca ou licença de imagem de artista.
